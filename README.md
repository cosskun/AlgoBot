# 🤖 AlgoBot Flutter: Çocuklar İçin Mobil Kodlama & Algoritma Macerası

AlgoBot Flutter, erken yaştaki çocukların eğlenerek algoritmik düşünme, sıralı mantık, döngüler, koşullar, fonksiyonlar ve hata ayıklama yeteneklerini geliştirmeleri için **Flutter (Dart)** ile geliştirilmiş yerel (native) bir mobil oyundur.

---

## 🌟 Öne Çıkan Özellikler

### 1. 👗 Bölüm Geçtikçe Açılan Avatar & Gardırop Sistemi
Çocukların oyundaki motivasyonunu yükseltmek amacıyla her dünyayı tamamladıklarında özel bir robot avatarı hediye edilir:
* 🤖 **Klasik Robi:** Başlangıç robotu (Sevimli mavi gövde, parlak yeşil gözler ve anten).
* 👨‍🚀 **Astro Robi:** 1. Dünya (Sıralama) bitince hediye edilir (Uzay kaskı & yıldız parıltısı).
* 🏎️ **Turbo Robi:** 2. Dünya (Döngüler) bitince hediye edilir (Alevli yarışçı kaskı).
* 🧙‍♂️ **Büyücü Robi:** 3. Dünya (Koşullar) bitince hediye edilir (Sihirli büyücü şapkası).
* 👑 **Kral Robi:** 4. Dünya (Fonksiyonlar) bitince hediye edilir (Altın taç & kraliyet pelerini).
* 🥷 **Siber Ninja:** 5. Dünya (Şampiyonluk) bitince hediye edilir (Neon siber ninja kostümü).

*Sol üstteki avatar butonuna basarak **Robi Kostüm Dolabı** açılabilir ve kazanılan tüm avatarlar arasında geçiş yapılabilir.*

---

### 2. 🗺️ 5 Farklı Algoritma Dünyası ve Müfredat
* 🧭 **1. Dünya: Sıralı Mantık (Sequencing):** Yön tayini, ileri adımlar, sağa/sola dönüşler, engellerden kaçma.
* 🔄 **2. Dünya: Tekrar Vadisi (Loops):** Desenleri keşfetme ve "X Kez Tekrarla" blokları ile kod verimliliği.
* 🔀 **3. Dünya: Karar Ormanı (Conditions):** "Eğer Engel Varsa" ve kilitli kapıları açan anahtar mekanizması.
* 🪄 **4. Dünya: Büyülü Fonksiyonlar (Functions):** Hareket dizilerini `F1` fonksiyonunda paketleyip ana kodda tek dokunuşla çağırma.
* 🛠️ **5. Dünya: Robot Tamirhanesi (Debugging):** Verilen hatalı algoritmaları inceleyip tamir etme bulmacaları.

## 🚀 Uygulamayı Çalıştırma

Proje dizinine gidin:
```bash
cd C:\Users\Developer6\.gemini\Project\AlgoBot_Flutter
```

### 🌐 1. Web Tarayıcısında Anında Çalıştırma (Chrome / Edge)
Ek bir emülatör başlatmadan doğrudan tarayıcıda test etmek için:
```bash
flutter run -d chrome
```

### 💻 2. Windows Masaüstü Olarak Çalıştırma
```bash
flutter run -d windows
```

### 📱 3. Android veya iOS Cihazında / Emülatörde Çalıştırma
Bir Android telefon bağlayarak veya Android Studio emülatörü açıkken:
```bash
flutter run
```
